# AI20.2 Phase 1 — Context-Driven Enrollment Wizard

## Objective

Redesign the Student Enrollment Wizard so it is driven by the existing Operational Context instead of asking the user to confirm information already known.

## Changes

### Wizard flow (before → after)

| Before | After |
|--------|-------|
| Step 1: College | *(removed — read-only header)* |
| Step 2: Academic Year | Step 1: Academic Year |
| Step 3: Scope | Step 2: Enrollment Scope |
| Step 4: Preview | Step 3: Preview |
| Step 5: Confirm | Step 4: Confirm |

### Read-only context header

The wizard displays at the top:

- **College Name** (from operational context / tenant college profile)
- **University Name** (from tenant college API)
- **Operational Context** age (`Selected 5 minutes ago`)

College ID, University ID, and database identifiers are **never** shown or editable.

### Files

| File | Role |
|------|------|
| `abhyanvaya-ui/src/components/enrollment/EnrollmentBatchWizard.tsx` | 4-step context-driven wizard |
| `abhyanvaya-ui/src/components/enrollment/WizardContextHeader.tsx` | Read-only context summary |
| `abhyanvaya-ui/src/utils/enrollmentWizardUtils.ts` | Step labels, scope helpers |
| `abhyanvaya-ui/src/utils/enrollmentWizardUtils.test.ts` | Unit tests |

## Constraints

- **UI only** — no API or enrollment pipeline changes
- Material UI, responsive layout
- Requires operational college context before proceeding
