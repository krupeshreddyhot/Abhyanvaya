# AI20.2 Phase 6 — Dashboard Insight Widgets

## Objective

Enhance the AI Enrollment dashboard with operational insight widgets, auto-refreshed via SignalR (no polling).

## Widgets

| Widget | Data source |
|--------|-------------|
| Current Active Batches | `batches` (Created/Running) |
| Today's Completed Batches | `batches.completedUtc` today |
| Students Processed Today | `dashboard.processedToday` |
| Average Processing Time | `dashboard.averageDuration` |
| Recognition Success Rate | `dashboard.successRate` |
| Embedding Success Rate | Derived from batch outcomes |
| Storage Health | `systemStatus` (R2/Storage) |
| Worker Health | `systemStatus.workerStatus` |
| Queue Depth | `dashboard.queueLength` |
| Embedded Students | `dashboard.embedded` |
| Recent Failures | Sum of `batch.failedCount` |

## UI

- Enterprise outlined cards with icons
- Color coding: success / warning / error accents
- Loading skeleton via `LinearProgress` while dashboard loads

## Files

| File | Role |
|------|------|
| `EnrollmentInsightsWidgets.tsx` | Widget grid |
| `EnrollmentDashboard.tsx` | Placement below workflow card |

## Constraints

- No business logic changes
- Charts deferred where single-value cards suffice
- SignalR refresh through existing dashboard context subscriptions

## Verification

1. Open Student Enrollment overview
2. Operational Insights section visible below workflow
3. Values update when batches complete (SignalR)
