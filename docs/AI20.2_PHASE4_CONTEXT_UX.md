# AI20.2 Phase 4 — Operational Context UX

## Objective

Improve the Enterprise Operational Context banner for clarity and enterprise styling.

## Before → After

| Before | After |
|--------|-------|
| Age | Selected 5 minutes ago |
| Renew | **Refresh Context** |
| Clear | Clear Context |
| — | Current College + University |
| — | Valid Until |
| — | Expires in 7h 54m |
| — | Change Context |

## Display

- **Current College** with optional code chip
- **Current University** (loaded from tenant college API)
- **Context Selected** relative time
- **Valid Until** formatted local timestamp
- **Time Remaining** (e.g. `7h 54m`)

## Actions (SuperAdmin)

- **Change Context** — opens college selector
- **Refresh Context** — calls `renewOperationalContext()`
- **Clear Context** — clears non-global context

## Files

| File | Role |
|------|------|
| `OperationalContextBanner.tsx` | Redesigned banner |
| `contextFormatUtils.ts` | Age / remaining formatters |
| `contextFormatUtils.test.ts` | Unit tests |

## Constraints

- UI only — no backend changes
- Material UI, responsive stack layout

## Verification

1. Select a college as SuperAdmin
2. Banner shows college, university, selected age, valid until, remaining time
3. **Refresh Context** extends session (renamed from Renew)
