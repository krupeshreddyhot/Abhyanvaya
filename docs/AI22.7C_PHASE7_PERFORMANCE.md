## Objective

Optimize capture/review media for constrained mobile devices — presentation/runtime only; no backend changes.

## Delivered

| Capability | Mechanism |
|------------|-----------|
| Lazy image loading | `LazyMediaImage`, filmstrip / gallery `loading="lazy"` |
| Adaptive image quality hint | `adaptiveImageQuality` + device capability profile |
| Virtualization threshold | `shouldVirtualizeList` helper for large galleries |
| Pause hidden video | `usePauseHiddenMedia` (visibility + IntersectionObserver) |
| Memory cleanup | Existing blob URL revoke on camera panel unmount |
| Low memory / bandwidth / slow CPU detect | `detectDeviceCapability` (`deviceMemory`, `connection`, cores) |
