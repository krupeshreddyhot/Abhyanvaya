---

## R1 — Image Acquisition UX

| Feature | Implementation |
|---------|----------------|
| Camera Ready / Loading / Error / Permission / Connected | `getCameraStatusView` + chips in `CameraCapturePanel` |
| Capture Success Card | `CaptureSuccessCard` — confirm before upload |
| Quality indicators | `getImageQualityIndicator` (stars) from existing blur score |
| Recognition readiness | `RecognitionReadinessBanner` |
| Coverage summary | `RecognitionCoverageSummary` |
| Progress timeline | `RecognitionProgressTimeline` (Upload→Queued→Detect→Match→Review→Finalize) |
| Snackbars | `AttendanceSnackbarProvider` + MUI Snackbar |
| Accessibility | Focus rings, ARIA labels, keyboard selection on gallery/captures |

---

## R2 — Image Collection Experience

| Feature | Implementation |
|---------|----------------|
| Gallery view | Responsive thumbnail cards in `ClassroomPhotoCollectionPanel` |
| Enterprise status colors | Waiting / Processing / Processed / Failed |
| Image cards + overlays | Sequence, quality, method, status overlays |
| Hover preview | Popover with large preview + metadata |
| DnD polish | Drop highlight, shadow, scale; reorder logic unchanged |
| Coverage dashboard | Dashboard variant above gallery |
| Optional labels | localStorage (`sessionImageLabels`) — no API |
| Batch actions | Replace All, Delete All, Retry Recognition, Sort |
| Performance | `loading="lazy"` thumbnails, memoized sort |
