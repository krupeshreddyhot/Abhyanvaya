# AI11.2.H4 – Validation Architecture

## Components

| Type | Location |
|------|----------|
| `IClassroomImageValidator` | `Abhyanvaya.Application/Common/Interfaces/` |
| `ClassroomImageValidator` | `Abhyanvaya.Infrastructure/Validation/` |

## Implemented validation

| Rule | Implementation |
|------|----------------|
| Supported format | `.jpg`, `.jpeg`, `.png`, `.webp` extension check |
| Maximum size | 15 MB |
| Minimum resolution | 640 × 480 pixels via ImageSharp `IdentifyAsync` |
| Corrupt image | Catches `UnknownImageFormatException`, `InvalidImageContentException` |
