# AI11.2.H1 – AttendanceSession State Machine Review

## Objective

Ensure all `AttendanceSessionStatus` changes flow through domain state machine methods.

## Replacements

| Location | Before | After |
|----------|--------|-------|
| `AttendanceSession.cs` | `public AttendanceSessionStatus Status { get; set; }` | `public AttendanceSessionStatus Status { get; private set; }` |
| `AttendanceSession.StateMachine.cs` – `Approve()` | `Status = AttendanceSessionStatus.Approved` | `TransitionTo(AttendanceSessionStatus.Approved)` |
| `AttendanceSession.StateMachine.cs` – `Cancel()` | `Status = AttendanceSessionStatus.Cancelled` | `TransitionTo(AttendanceSessionStatus.Cancelled)` |
| `ClassroomRecognitionPipeline.cs` – catch block | Error fields only; status unchanged | `session.MoveToFailed()` |
| `AttendanceTestDataFactory.cs` | `session.Status = AttendanceSessionStatus.AwaitingReview` | `AttachClassroomImage` → `MoveToPending()` → `MoveToProcessing()` → `MoveToAwaitingReview()` |

## New state machine method

| Method | Transition |
|--------|------------|
| `MoveToFailed()` | Draft/Pending/Processing → Failed |

## Allowed transitions (extended)

- Approve shortcuts: Draft/Pending/Processing/Failed → Approved (preserved behavior)
- Cancel: Draft/Pending/Processing/AwaitingReview/Approved/Failed → Cancelled
- Failed: Draft/Pending/Processing → Failed

## Remaining direct assignments (internal only)

| Location | Purpose |
|----------|---------|
| `AttendanceSession.Factory.cs` | Initial `Status = Draft` during aggregate construction |
| `TransitionTo()` | Sole internal mutator for workflow transitions |

## Production callers (unchanged behavior)

| Method | Caller |
|--------|--------|
| `MoveToPending()` | `AttendancePhotoService`, `AttendanceSessionCreator`, `ClassroomRecognitionPipeline` |
| `MoveToProcessing()` | `ClassroomRecognitionPipeline` |
| `MoveToAwaitingReview()` | `ClassroomRecognitionPipeline` |
| `MoveToFailed()` | `ClassroomRecognitionPipeline` (failure path) |
| `Approve()` | `AttendanceSessionFinalizer` |
