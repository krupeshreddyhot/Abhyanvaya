## Objective

Mobile-first classroom dashboard summarizing today’s class context and quick-starting AI Attendance.

- `getAuthenticatedFacultyInfo` / operational faculty display

## Display

- Today’s classes count
- Current class card
- Next class slot (ready for schedule data when available)
- Attendance / recognition status
- Quick Start AI Attendance
- Recent sessions (latest AI session id)
