# AI20.1 Database Rollout

## Staging

1. Snapshot production database
2. Run `MigrationCompatibilityValidator`
3. Apply pending migrations
4. Run enrollment smoke tests

## Production

1. Maintenance window (if large migration)
2. Apply migrations
3. Validate schema report
4. Deploy API with AI20.1 startup validation

## Partial Schema Recovery

If `FixMissingEnrollmentSchema` was applied manually, EF history must include migration `20260719040000_FixMissingEnrollmentSchema`.

## Rollback Procedure

1. Revert API to previous version
2. Schema rollback only with DBA-authored script
3. Never assume EF `Down()` on idempotent fix migration
