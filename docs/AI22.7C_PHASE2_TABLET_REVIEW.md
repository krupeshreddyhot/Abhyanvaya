## Objective

Optimize `RecognitionReviewWorkspace` / `RecognitionReviewPanel` for iPad, Android tablet, and Windows tablet — stylus-friendly — without changing desktop.

## Architecture impact

- `useMobilitySurface().isTabletReview` scales touch targets, filmstrip thumbnails, and landscape min-heights.
- Resizable panels remain the single desktop/tablet grid source of truth (AI22.7B prefs).
- `TabletReviewShell` exported as a reusable shell / extension point; panel applies tablet rules in-place to avoid forking review state.

## Enhancements

- Two-column landscape emphasis + taller review canvas
- Larger thumbnails / student cards / 44px+ touch targets
- Persistent sticky toolbar (existing `StickyReviewToolbar`)
- Stylus + pen swipe navigation via existing pointer handlers
