# Faculty Command Center Guide

Navigate to **Dashboard** (Faculty) or `/dashboard/faculty`.

1. Review Current / Next class cards.
2. Use KPI strip for pending attendance and recovery.
3. Open Insights for composed alerts (not generative AI).
4. Filter Activity Timeline: Today / Week / Month.
5. Quick Actions: Take Attendance, Faculty Workspace, Recovery, Reports, Timetable.
6. Customize via `/dashboard/preferences`.

Faculty Workspace (`/faculty`) remains the detailed operational workspace.
