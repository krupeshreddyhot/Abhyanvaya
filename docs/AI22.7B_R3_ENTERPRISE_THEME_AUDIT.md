## Remaining exceptions (intentional technical debt)

| Area | Why retained |
|------|----------------|
| `enterpriseTokens.ts` / `createEnterpriseTheme.ts` hex values | **Source of truth** for the theme (not page-level hardcoding) |
| `confidenceColor.ts` / `enterpriseConfidence.ts` / `confidenceHeatMap.ts` | Domain overlay colors for photo readability; mirrored into `palette.recognition` — future debt to read from `useTheme()` in review overlays without redesign |
| Gallery canvas `grey.900` / photo stage | Must stay dark under photos for contrast; media plane, not chrome |
| Overlay label `rgba(0,0,0,0.72)` | Readability on classroom imagery (documented media exception) |
| Third-party / generated assets | Out of scope |

## Recognition Review / Attendance / Enrollment

No workflow or structural redesign. Chrome inherits ThemeManager. Overlay/domain color utilities remain as exceptions above so photo canvases stay readable in Light and Dark.
