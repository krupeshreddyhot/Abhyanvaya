# AI20.1 Security Review

## Scope

SignalR authorization, tenant context, REST APIs, background workers, storage, audit, telemetry.

## Findings Addressed

| Issue | Resolution |
|-------|------------|
| Unauthenticated batch group join | `IEnrollmentAuthorizationService` |
| `Clients.All` leak | Removed; tenant/batch groups only |
| Batch enumeration | Uniform Forbidden response |
| Missing audit | `IAuditService` on denied access |

## OWASP Checklist (summary)

| Category | Status |
|----------|--------|
| Broken Access Control | Mitigated (tenant-scoped auth) |
| Cryptographic Failures | JWT required; secrets via env |
| Injection | Parameterized EF/SQL |
| Security Misconfiguration | Startup validator (production fail-fast) |
| Identification/Authentication | JWT + hub `[Authorize]` |
