# AI22.6 Migration Guide

## Backend

1. Ensure `AddTenantContextPlatform(configuration)` is called (already in `DependencyInjection.cs`).
2. Configure `TenantContext` section in `appsettings.json`.
3. Optional: swap `IContextPersistenceProvider` implementation in DI for Redis/SQL direct providers.

## Frontend

1. Replace page-level `needsCollegeSelection` checks with `ContextAwareLayout` or `OperationalContextGuard`.
2. Subscribe to context events via `useTenantContext().subscribe()` instead of manual refresh wiring.
3. Use `hasOperationalContext` instead of deprecated `needsCollegeSelection`.

## No breaking API changes

Existing endpoints unchanged:

- `GET /api/context`
- `POST /api/context/college`
- `DELETE /api/context`
- `GET /api/context/available-colleges`

New endpoints:

- `GET /api/context/recent-colleges`
- `POST /api/context/refresh`
- `GET /api/context/diagnostics` (SuperAdmin)
