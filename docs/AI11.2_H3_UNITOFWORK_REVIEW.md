# AI11.2.H3 – Unit of Work Review

## Standard

Application services own transactions via `IUnitOfWork`. Controllers never call `SaveChangesAsync`.

## Updated services

| Service | Before | After |
|---------|--------|-------|
| `ClassScheduleService` | `_context.SaveChangesAsync()` | `ConcurrencyExceptionHelper.SaveChangesAsync(_unitOfWork)` |
| `AttendancePhotoService` | N/A (was `ClassroomPhotoService` in API) | `ExecuteInTransactionAsync` + `ConcurrencyExceptionHelper` |
| `AttendanceSessionCreator` | N/A | `ExecuteInTransactionAsync` + `ConcurrencyExceptionHelper` |
| `ClassroomRecognitionPipeline` | `_unitOfWork.SaveChangesAsync()` | `ConcurrencyExceptionHelper.SaveChangesAsync(_unitOfWork)` |
