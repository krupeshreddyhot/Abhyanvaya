# AI20.1 Environment Variables

## Required (Production)

| Variable | Description |
|----------|-------------|
| `Jwt__Key` | JWT signing secret |
| `Jwt__Issuer` | Token issuer |
| `Jwt__Audience` | Token audience |
| `ConnectionStrings__DefaultConnection` | PostgreSQL |
| `ArtifactStorage__Provider` | `r2` in production |
| `ArtifactStorage__R2__Endpoint` | Cloudflare R2 endpoint |
| `ArtifactStorage__R2__AccessKeyId` | R2 access key |
| `ArtifactStorage__R2__SecretAccessKey` | R2 secret |
| `ArtifactStorage__Bucket` | R2 bucket name |
| `StudentPhotoProvider__ExamBranch__BaseUrlTemplate` | Photo URL template |
| `UseRedis` | `true` in production |

## Development

| Variable | Default |
|----------|---------|
| `ArtifactStorage__Provider` | `local` |
| `ArtifactStorage__PhysicalRoot` | `App_Data/artifacts` |
| `EnrollmentBackground__Enabled` | `false` |

## Optional

| Variable | Purpose |
|----------|---------|
| `EnrollmentProgressBroadcast__Enabled` | SignalR progress broadcaster |
| `EnrollmentRecovery__Enabled` | Recovery worker |
| `InsightFace__ModelDirectory` | ONNX models path |

## SignalR / Workers

SignalR uses the same JWT as REST. Workers require `EnrollmentBackground:Enabled=true` in production.
