# AI22.6 Phase 1 — Context Persistence Abstraction

## Objective

Replace the direct `ICacheService` dependency in tenant context storage with `IContextPersistenceProvider`.

## Architecture

```
ITenantContextStore
        ↓
IContextPersistenceProvider
        ↓
DistributedCacheContextPersistenceProvider
        ↓
ICacheService (SmartCache → Memory / Redis)
```

## Interface

`IContextPersistenceProvider` exposes:

- `SaveAsync`
- `LoadAsync`
- `DeleteAsync`
- `ExistsAsync`
- `RefreshAsync`

## Future providers

Additional implementations can be registered in DI without changing platform code:

- Redis direct
- SQL Server
- PostgreSQL
- Azure Cache
- AWS ElastiCache
- In-Memory

## Configuration

`appsettings.json`:

```json
"TenantContext": {
  "ExpirationHours": 8,
  "RecentCollegesMax": 10,
  "CleanupIntervalMinutes": 15
}
```
