# AI20.2 Phase 2 — Enrollment Summary Preview

## Objective

Provide administrators with a complete enrollment summary before starting a batch, using backend readiness and dashboard APIs (no hardcoded values).

## Preview cards

The Preview step displays enterprise summary cards for:

| Field | Source |
|-------|--------|
| College / University | Operational context + tenant college |
| Academic Year / Scope | Wizard state |
| Eligible Student Count | `previewBatch` API |
| Photo Provider | `configuration` |
| Recognition Engine | `configuration` |
| Storage Provider | `configuration` |
| Embedding Model / Size | `configuration` |
| Similarity Metric | Derived from recognition engine |
| Worker Status | `systemStatus` / `readiness` |
| Download Threads | `configuration` |
| Estimated Processing Time | `dashboard.averageDuration` + eligible count |
| Retry Policy | `configuration` |
| Current Queue Length | `dashboard` |
| Active Batches | `readiness.runningBatchId` |
| Queue Completion Estimate | Queue length × per-batch estimate |

### Warnings

When `readiness.canStart` is false, warning alerts list `readiness.reasons`.

## Files

| File | Role |
|------|------|
| `EnrollmentSummaryPreview.tsx` | Composes summary from API DTOs |
| `EnterpriseSummaryGrid.tsx` | Reusable enterprise card grid |
| `enrollmentWizardUtils.ts` | Duration parsing and estimates |

## Constraints

- No enrollment engine changes
- Estimates derived from `averageDuration` and `downloadThreads`, not constants

## Verification

1. Complete wizard steps 1–2 with valid scope
2. Preview step shows all cards populated from live API data
3. Induce a readiness failure — warning cards appear
