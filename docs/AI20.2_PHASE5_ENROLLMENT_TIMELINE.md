# AI20.2 Phase 5 — Enrollment Timeline

## Objective

Provide administrators with a read-only enrollment timeline in batch details, updated via SignalR.

## Timeline events

| Event | Trigger |
|-------|---------|
| Batch Created | `batch.createdUtc` |
| Download Started | `batch.startedUtc` |
| Download Completed | Derived from progress counts |
| Embedding Started | Progress embedding > 0 |
| Embedding Completed | Progress completed > 0 |
| Upload Started | Progress completed > 0 |
| Validation Completed | Progress completed > 0 |
| Batch Finished | `batch.completedUtc` |
| Retry Events | `progress.failed > 0` |

Each event shows:

- Timestamp (or "In progress")
- Student count where available
- Warning/error chips for failures

## UI

- Material UI `@mui/lab` Timeline
- Collapsible accordion (default expanded)
- Color-coded dots by severity

## Files

| File | Role |
|------|------|
| `EnrollmentTimeline.tsx` | Timeline presentation |
| `enrollmentStageUtils.ts` | `buildTimelineEvents()` |
| `BatchDetailsDialog.tsx` | Integration |

## Constraints

- Read-only
- SignalR-driven updates through shared progress state
- No pipeline changes

## Verification

1. Open batch details for a running batch
2. Expand Enrollment Timeline
3. Observe events append as progress updates arrive
