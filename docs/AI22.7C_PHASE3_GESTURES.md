## Objective

Enterprise touch interactions on the existing classroom image viewer.

## Gestures

| Gesture | Behavior |
|---------|----------|
| Swipe left / right | Next / previous classroom image |
| Pinch | Zoom |
| Double-tap | Toggle ~2× zoom |
| Two-finger pan | Pan while pinched |
| Long-press | Context menu (Reset / Fit screen) |
| overscroll-behavior | Rubber-band prevention on canvas |

Mouse middle/Alt-drag, wheel zoom, and keyboard shortcuts remain unchanged.

## Architecture impact

- Helpers in `mobility/gestures.ts` (+ reuse of `theme/tabletExperience.resolveSwipe`).
- Touch logic lives in `useEnterpriseImageViewer` and `ClassroomPhotoPanel`.
- Accessibility: aria-labels updated; keyboard path preserved.
