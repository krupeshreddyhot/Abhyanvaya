# AI20.1 Migration Guide

## Validator

`IMigrationCompatibilityValidator` detects missing enrollment tables/columns against expected AI20 schema.

## Modes

| Mode | Meaning |
|------|---------|
| FreshInstall | No migrations applied |
| Upgrade | Schema complete |
| PartialSchema | Missing columns |
| LegacyDatabase | Missing tables |

## Rollout

1. Run validator on staging copy
2. Apply EF migrations in order
3. Re-run validator — expect `IsCompatible=true`
4. For partial manual schema, migration `20260719040000_FixMissingEnrollmentSchema` uses idempotent SQL

## Rollback

EF `Down()` may not match manually patched databases. Prefer forward-fix migrations.

See `AI20.1_SCHEMA_COMPATIBILITY.md` and `AI20.1_DATABASE_ROLLOUT.md`.
