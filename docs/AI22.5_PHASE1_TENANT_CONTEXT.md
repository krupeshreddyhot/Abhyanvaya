# AI22.5 Phase 1 — Enterprise Tenant Context Framework

## Purpose

Provide a **platform-level operational tenant context** independent of JWT claims. SuperAdmin users operate in global JWT scope (`TenantId = 0`) but must select a college context for tenant-scoped modules. College admins continue to use JWT tenant assignment automatically.

## Core Components

| Component | Responsibility |
|-----------|----------------|
| `ITenantContextService` | Get/set/clear/validate context; resolve effective tenant |
| `ITenantContextStore` | Persistence abstraction (distributed cache via `ICacheService`) |
| `ITenantContextCollegeCatalog` | Accessible colleges + selection validation |
| `TenantContextSnapshot` | Immutable operational context model |
| `TenantContextMiddleware` | Loads context per HTTP request; binds `ITenantContextAccessor` |

## Model — `TenantContextSnapshot`

- `UserId`, `Role`
- `SelectedCollegeId`, `SelectedCollegeName`, `SelectedCollegeCode`
- `TenantId` (effective data scope)
- `ContextType` (`Global`, `College`, …)
- `CreatedUtc`, `IsGlobal`, `ContextSource`

**Not stored in JWT. No token regeneration.**

## Service Methods

- `GetCurrentContextAsync()`
- `SetCurrentContextAsync(collegeId)` — SuperAdmin only
- `ClearContextAsync()` — SuperAdmin only
- `ValidateContextAsync()`
- `IsGlobalContext()` / `IsCollegeContext()`
- `ResolveForOperation()` — structured `ContextRequired` when unresolved
- `ApplyOperationalTenantAsync()` — binds accessor for EF/services

## Persistence

`DistributedCacheTenantContextStore` → `ICacheService` key `tenant-context:v1:{userId}` (8h TTL). Supports Redis or in-memory distributed cache for multi-server deployments.

## Context Resolution Priority (Phase 4)

1. **College Admin** → JWT `TenantId > 0`
2. **SuperAdmin** → operational college selection (`TenantId` from selected college)
3. **Neither** → `400` with `{ errorCode: "ContextRequired" }` (no exceptions)

## Hierarchy (Phase 6 — design only)

`ContextType` enum reserves: `Global`, `University`, `College`, `Campus`, `Department`, `Course`, `Section`. Only **Global** and **College** are implemented. Future scopes implement `ITenantContextHierarchy`.

See [AI22.5_HIERARCHY_ARCHITECTURE.md](./AI22.5_HIERARCHY_ARCHITECTURE.md).

## Migration Guide

1. Register `services.AddTenantContextPlatform()` in Infrastructure DI.
2. Add `app.UseTenantContext()` after `UseAuthentication()` in `Program.cs`.
3. Replace direct `_currentUser.TenantId` assumptions in controllers with `RequireTenantContext()`.
4. SuperAdmin UI: wrap app in `TenantContextProvider`; show `CollegeContextSelector` when `needsCollegeSelection`.
5. No JWT or pipeline changes required.
