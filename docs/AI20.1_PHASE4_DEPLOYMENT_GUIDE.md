# AI20.1 Phase 4 — Deployment Guide

## Startup Validation

`IEnrollmentConfigurationValidator` runs via `EnrollmentStartupValidationHostedService` on application start.

| Environment | Behavior |
|-------------|----------|
| Development | Warnings logged; startup continues |
| Production | Failures stop the application |

## Validated Components

- JWT (`Jwt:Key`, `Issuer`, `Audience`)
- ExamBranch photo URL template
- Artifact storage (local dev / R2 production)
- Redis (`UseRedis`)
- Enrollment background workers

## Deployment Checklist

### Fresh Install
1. Apply EF migrations
2. Set production secrets (see `AI20.1_ENVIRONMENT_VARIABLES.md`)
3. Enable Redis and enrollment workers
4. Configure Cloudflare R2
5. Verify health endpoints

### Upgrade
1. Run `MigrationCompatibilityValidator`
2. Apply pending migrations
3. Validate schema report
4. Rolling API restart

### Rollback
1. Revert API deployment
2. Do not downgrade schema without DBA review

### Disaster Recovery
1. Restore PostgreSQL
2. Restore R2 bucket
3. Re-run startup validation
