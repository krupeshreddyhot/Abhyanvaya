# AI20.1 Health Checks

## Platform Health Components

| Component | Provider | Validates |
|-----------|----------|-----------|
| Storage | `StorageHealthCheckProvider` | Local path or R2 credentials |
| Recognition | `RecognitionHealthCheckProvider` | ONNX models + DB |
| Embedding | `EmbeddingEngineHealthCheckProvider` | InsightFace models |
| Workers | `WorkerHealthCheckProvider` | Worker registration |
| Database | `DatabaseHealthCheckProvider` | EF connectivity |

## Startup Validation

`EnrollmentConfigurationValidator` complements runtime health checks with configuration-level validation at boot.

## Telemetry

- Configuration failures logged at Error/Critical
- Unauthorized SignalR attempts via `IEnrollmentAuthorizationTelemetry`
- Migration compatibility via `MigrationCompatibilityValidator`

## Enrollment Readiness

Dashboard readiness endpoint aggregates photo provider, storage, recognition, workers, and configuration state.
