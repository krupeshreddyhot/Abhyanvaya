# AI20.2 Phase 3 — Stage-Aware Progress

## Objective

Replace the generic progress bar with stage-aware progress driven by existing SignalR `BatchProgress` events (no polling).

## Stages

1. Downloading Photos
2. Validation
3. Generating Embeddings
4. Uploading Artifacts
5. Completed

Each stage card shows:

- Current count / total count
- Percentage
- Estimated remaining (current stage)
- Overall percentage and ETA

## Timeline navigation

Material UI `Stepper` displays:

- **Previous** stages (marked Done)
- **Current** stage (highlighted)
- **Upcoming** stages

## Actions

| Action | Status |
|--------|--------|
| Cancel | Wired to `cancelBatch` |
| Retry | Wired to `retryBatch` |
| Pause | Disabled — future release |
| Resume | Future |

## Files

| File | Role |
|------|------|
| `EnrollmentStageProgress.tsx` | Stage stepper + per-stage cards + actions |
| `BatchDetailsDialog.tsx` | Integrates stage progress |
| `enrollmentStageUtils.ts` | Stage definitions and mapping |
| `enrollmentStageUtils.test.ts` | Unit tests |

## Data source

Uses `BatchProgressDto` from `EnrollmentDashboardContext.batchProgress` updated via SignalR hub `/hubs/enrollment`.

## Constraints

- Presentation only — no pipeline changes
- No polling

## Verification

1. Start or open an active batch
2. Batch Details shows stage stepper updating live
3. Cancel / Retry visible when user has `Enrollment.Manage`
