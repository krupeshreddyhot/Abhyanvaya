# AI30.2A.3 — Publishing Lifecycle

**States on Timetable:** Draft | Locked | Published | Archived  

**Rules:** Published read-only; one Published timetable per AcademicYear + Department; Archive hides from default lists.  
**API:** `POST .../timetables/{id}/publish|archive`  
**UI:** Publishing page + designer actions. No Attendance / AI / conflict engine.
